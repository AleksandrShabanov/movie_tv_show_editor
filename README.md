# Movie Top Video Pipeline

## Быстрый старт

### 1. Установите зависимости

```bash
pip install requests pillow python-dotenv
```

Системные утилиты (должны быть в PATH):
```bash
# macOS
brew install ffmpeg yt-dlp

# Ubuntu/Debian
sudo apt install ffmpeg && pip install yt-dlp
```

### 2. Настройте ключи

Создайте файл `.env` в корне проекта:

```env
VOICER_API_KEY=ваш_ключ
TMDB_API_KEY=ваш_ключ
OMDB_API_KEY=ваш_ключ
```

### 3. Подготовьте список фильмов

Создайте `movies.json` по образцу `movies_example.json`:

```json
{
  "voice_id": "iP95p4xoKVk53GoZ742B",
  "movies": [
    {
      "number": 1,
      "title": "Inception",
      "year": 2010,
      "voiceover_text": "Текст для войсовера..."
    }
  ]
}
```

### 4. Запуск

```bash
# Полный пайплайн
python pipeline.py movies.json --output final.mp4

# Без генерации войсовера (если MP3 уже есть)
python pipeline.py movies.json --output final.mp4 --skip-voiceover

# Указать свою рабочую директорию
python pipeline.py movies.json --output final.mp4 --work-dir ./my_work
```

Готовое видео появится по пути, указанному в `--output` (по умолчанию `final.mp4`).

## О проекте

Пайплайн для автоматической сборки YouTube-видео в формате «топ фильмов». По каждому фильму из JSON-файла он генерирует войсовер, скачивает трейлер и постер, монтирует сегмент с титрами, а затем склеивает всё в одно финальное видео.

**Что делает пайплайн:**

1. **Войсовер** — отправляет текст в VoicerAPI (ElevenLabs под капотом), ждёт генерации и скачивает MP3
2. **Трейлер** — ищет и скачивает официальный трейлер с YouTube через `yt-dlp`, обрезает вступительные логотипы
3. **Постер** — скачивает постер через TMDB API, с фолбэком на OMDB
4. **Монтаж сегмента** — собирает постер с эффектом → трейлер → войсовер поверх, накладывает титры (номер и название фильма) через Pillow
5. **Финальная сборка** — склеивает все сегменты в одно видео

**Стек:**

| Инструмент | Роль |
|---|---|
| `ffmpeg` | Видеомонтаж, кодирование, конкатенация |
| `yt-dlp` | Скачивание трейлеров с YouTube |
| `Pillow` | Генерация PNG-оверлеев с текстом |
| `requests` | HTTP-запросы к API |
| `python-dotenv` | Загрузка ключей из `.env` |
| VoicerAPI | Генерация войсовера (ElevenLabs) |
| TMDB API | Постеры фильмов |
| OMDB API | Резервный источник постеров |

**Структура рабочей директории** (создаётся автоматически):

```
pipeline_work/
├── trailers/    # скачанные трейлеры
├── posters/     # постеры фильмов
├── voiceovers/  # сгенерированные MP3
└── segments/    # смонтированные сегменты
```

Уже готовые файлы пропускаются при повторном запуске — можно безопасно прерывать и продолжать.
